CS STUDY ROTATION — QUICK GUIDE
================================

How to study an algorithm
-------------------------
1. State the problem and the input constraints.
2. Write the brute-force approach first.
3. Identify the repeated work or useful invariant.
4. Choose the data structure that supports the needed operations.
5. Explain correctness before writing code.
6. Give time and space complexity.
7. Test empty, one-item, duplicate, sorted, and extreme inputs.

Common complexity targets
-------------------------
Array scan                    O(n)
Binary search                 O(log n)
Hash lookup, average          O(1)
Balanced tree operation       O(log n)
Comparison sorting            O(n log n)
Graph traversal               O(V + E)
All-pairs shortest paths      O(V^3)

Interview reminder
------------------
Clarify -> Examples -> Brute force -> Optimize -> Prove -> Code -> Test

Do not memorize code without understanding its invariant. Try to explain each
file aloud, then recreate it without looking.
