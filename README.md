# CS Study Rotation for Windows

A small, user-controlled Windows utility that rotates through computer-science study notes in Notepad. While it is enabled, each file is displayed for a random 5–10 minutes and an Alt+Tab is sent every 30–40 seconds. The user can stop the rotation at any time with the included Stop launcher.

The installer creates:

- `CS Study Rotation App` on the current user's Windows Desktop
- `CS Study Files` on the current user's Windows Desktop

## Requirements

- Windows 10 or Windows 11
- Windows PowerShell 5.1 or newer
- Notepad

Implementation and installation instructions will be added as the app is built.
